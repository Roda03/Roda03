**Proyecto en desarrollo**

Aplicación para conectar empresas que necesitan transportar mercaderías con transportistas registrados.

**Tecnologías:** Laravel, PostgreSQL, React Native, Expo y Laravel Sanctum.

- Gestión segura de contraseñas.
- Registro de auditoría.
